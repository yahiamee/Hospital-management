# Hospital Management System

A PHP-based hospital management project built as a practical healthcare software application.

## Overview

This repository represents an early web-development project focused on organizing hospital-related workflows through a browser-based system.

## Technology

- PHP
- HTML / CSS
- Web-based application architecture

## Project Goal

The project was created to explore how software can support healthcare administration and centralize common hospital-management activities in one system.
